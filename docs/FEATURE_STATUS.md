## 1. 건물 표시

| 기능 | 상태 | 비고 |
|------|------|------|
| 층 자동 생성 (지상/지하) | ✅ | `buildingData.ts` / `buildDisplayFloors()` |

| 초기 문 상태 자동설정 | ✅ | 화점층 이하 open, 화점층 위·RF closed |
