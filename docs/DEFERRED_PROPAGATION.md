## 1. 이 문서의 목적

훈련모드(무플) UI를 개선하는 동안 **다른 모드에 손대야 할 이유가 계속 발견된다.** 그때마다 범위를 넓히면 무플 작업이 끝나지 않는다.

그래서 규칙을 하나 둔다.

> **무플 작업 중 다른 모드의 수정이 필요해지면, 고치지 말고 여기에 적는다.**
> 훈련모드(무플) UI·기능이 완성된 뒤 이 문서를 펼쳐 한 번에 반영한다.

이 문서는 **작업 목록이 아니라 관측 기록**이다. 무플 작업이 진행되면서 항목이 계속 늘어난다. 완료 시점에 §4의 반영 순서로 옮겨 실행한다.

### 1.1 네 모드의 경계 (2026-08-18 코드 실측)

| 모드 | 현재 구현 | 경계 상태 |
|---|---|---|
| **설정모드** | `/settings` · `components/settings/` 10개 패널 | ✅ 깨끗 — `/play`와 컴포넌트 공유 **0건** |
| **훈련모드(무플)** | `/play` · `building`·`center`·`left`·`right`·`panels`·`events`·`drawing`·`shared` | ★ 현재 작업 대상 |
| **훈련모드(지휘)** | **미구현** — `/instructor` 라우트 없음 | `ChecklistPanel`·`ChecklistView` 재사용 예정 |
| **분석(창)** | `overlays/AnalysisModal.tsx`(17행) — `/play` 내부 모달 | ⚠ `right/CommandInfo`를 그대로 재사용. 무플에 종속 |

설정모드가 `/play`와 컴포넌트를 하나도 공유하지 않는다는 점이 유리하다. 무플 작업이 설정모드를 **깨뜨릴 일은 없고**, 나중에 같은 개선을 이식하면 되는 관계다.

반대로 분석창은 무플 우측 패널 컴포넌트를 직접 띄우므로 **무플을 고치면 자동으로 따라 변한다.** 이건 이득일 수도 손해일 수도 있어 건별 판단이 필요하다.

## 2. 기록 규칙

작업 중 다른 모드 수정이 필요해지면 §3 표에 한 줄 추가한다.

| 열 | 쓰는 법 |
|---|---|
| ID | `P-n` 일련번호 |
| 발생 | 어느 무플 작업(W-n)에서 나왔는지 |
| 영향 모드 | 설정 / 지휘 / 분석 (복수 가능) |
| 관측 내용 | **무엇을 발견했는지.** 해결책이 아니라 사실을 적는다 |
| 필요 작업 | 나중에 해야 할 일. 아직 확정 아니어도 됨 |
| 판정 | `필수` — 안 하면 그 모드가 깨진다<br>`정합` — 안 해도 동작하지만 일관성이 무너진다<br>`기회` — 김에 같이 하면 좋은 것 |

**무플 작업 중에는 이 표의 어떤 항목도 실행하지 않는다.** 예외는 §3에서 `즉시`로 표시한 항목뿐이며, 그건 "안 고치면 무플 작업 자체가 막히는 경우"에만 붙인다.

## 4. 반영 순서 (훈련모드 무플 완성 후)

무플 UI·기능이 완성된 뒤 아래 순서로 이 문서를 소진한다. 순서의 근거는 **의존 방향**이다 — 지휘모드가 무플의 체크 구조에 의존하고, 분석창이 무플의 우측 패널에 의존한다.

| 순서 | 대상 | 소진할 항목 | 비고 |
|---|---|---|---|
| 1 | **훈련모드(지휘) 신설** | P-2 | [MASTER_PLAN.md §7.1](MASTER_PLAN.md) 향후 단계. 서버 + 동기화 + `/instructor`. D-5로 범위가 커졌다 — 지휘절차는 `CommandProcedureTrainingBox`와 별개 경로 설계 필요 |
| 2 | **설정모드 정합** | ~~P-5~~ · **P-8** | ⚠ **2026-08-24 D-7로 순서가 앞당겨져 별도 브랜치(`feat/settings-ui-redesign`)에서 진행 중이다.** P-5는 해소됐고, 실작업은 [SETTINGS_MODE_UI_PLAN.md](SETTINGS_MODE_UI_PLAN.md) S-0~S-6이 대체한다. **P-8(전역 `:root` 토큰 공유)은 그 작업 중에 지켜야 할 조건이라 S-1에서 소진한다** |
| 3 | **전역 내비게이션** | P-4 | 세 모드가 확정된 뒤에 손대야 한 번에 끝난다 |
| 4 | **분석창 재설계** | P-1 · P-6 | 가장 독립적이라 마지막. 훈련 통계 구현이 본체 |

~~P-7~~ 는 D-5로 전제가 사라져 별도 반영 대상이 아니다 — 남은 질문은 P-2에 흡수됐다.

각 단계 착수 시 해당 항목만 이 문서에서 잘라내 별도 계획서로 옮기고, 여기에는 완료 표시만 남긴다.
